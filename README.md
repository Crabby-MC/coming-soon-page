# ExoraGames.io

A full, polished, single-page website for **ExoraGames** — a passionate Minecraft game development studio.

> "Making communities alive!"

## Sections

- **Hero** — Bold heading, tagline, animated background, CTA
- **Stats Bar** — 2 Games · 5 Team Members · Thousands of Players · Minecraft Platform
- **Games** — CrystalChaos & FrootlySMP showcase cards
- **About** — Studio mission and description
- **Team** — 5 team member placeholder cards
- **Contact** — Styled contact form + social links
- **Footer** — Copyright, socials, tagline

## Tech Stack

- Pure **HTML / CSS / JS** — no frameworks
- [Google Fonts](https://fonts.google.com/) (Outfit + Inter)
- [Font Awesome](https://fontawesome.com/) icons
- Responsive (mobile → desktop)
- Smooth scroll, fade-in animations, animated counters
